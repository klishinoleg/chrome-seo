# SEO / инспектор 0.1.0

Локальное расширение Chrome Manifest V3 на русском языке. Установка: откройте chrome://extensions, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите C:/ai/chrome-seo. Сборка и зависимости не нужны.

- META: title, description, canonical, robots, язык, Open Graph, H1–H6, изображения/alt и число слов.
- KEYS: независимые слова через пробел, Unicode-границы, подсчёты по категориям и обратимая разноцветная подсветка. Всего = BODY; P/A пересекаются с BODY, заголовки считаются отдельно; TITLE/META не входят в BODY. OTHER — текст вне ближайших P/A/H1–H6.
- MICRO: JSON-LD с ошибками разбора, microdata и RDFa.
- LINKS: все внешние HTTP(S)-анкоры, фильтр по домену, rel и подсветка. Красный: nofollow/ugc/sponsored либо robots nofollow/none; зелёный: эти ограничения отсутствуют. Это не проверка индексации. Поддомены считаются внешними.
- SEARCH: обычные запросы Google/Яндекса, отдельные site:домен и site:текущий URL. Запрос, целевой домен и независимый фильтр ссылок сохраняются локально. На www.google.com/search, www.google.ru/search, yandex.ru/search и yandex.com/search подсвечиваются результаты целевого домена. Позиции и индексация не проверяются.

Разрешения: activeTab, scripting, storage. content_scripts ограничены четырьмя указанными поисковыми доменами. Данные не отправляются на сервер; поисковые кнопки открывают выбранный запрос в новой вкладке. Анализируется DOM главного документа на момент нажатия. Внутренние страницы Chrome, магазин расширений, iframe, shadow DOM, HTTP-заголовки и внешние документы не анализируются. Подсветка требует CSS Custom Highlight API; очистка удаляет только собственную подсветку расширения. Динамические изменения страницы могут потребовать повторного анализа.

Проверки: `npm install`, `npm run check`, `npm test` (браузерные поведенческие проверки через Playwright). В Windows runner использует установленный Chrome; иначе установите браузер командой `npx playwright install chromium`. Путь можно указать переменной `CHROME_PATH`. Для использования расширения зависимости не нужны.

Проверено: 12 проверок анализатора и 26 интеграционных проверок. Runner загружает исходное расширение в Chrome, проверяет content script поиска и local storage; формы popup тестируются через мост к анализатору в настоящем браузере. Автоматизация не нажимает кнопку расширения на панели Chrome для выдачи activeTab.

Справка: [Chrome Scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting), [Google о rel у исходящих ссылок](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links).
