# 0.1.15

[Все выпуски](README.md) · [Руководство](../USAGE.md)

- Условная вкладка GSC для отчёта источников ссылок Search Console: ручное сохранение страниц и дневная история изменений.
- Снимки пагинации дополняют один замер за день по Москве. День без изменений обновляет время проверки без новой строки истории.
- Зелёный NEW, первая дата наблюдения, давность и дневная разница показываются прямо в таблице. Неполный сбор не объявляет скрытые источники удалёнными.
- Отдельный JSON каждого ресурса в папке списков, локальная копия, безопасное объединение журналов и ожидание синхронизации при недоступной папке.
- Включены ранее подготовленные ссылки Google/Яндекс в шапке для ручного поиска текущего URL в индексе.
- Учтено видимое поле textarea Яндекса. «Продолжить» повторяет переход без повторного подсчёта уже сохранённой страницы; сбор конкурентов продолжается по тому же запросу.
