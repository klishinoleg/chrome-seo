# 0.1.16

[Все выпуски](README.md) · [Руководство](../USAGE.md)

- «Сохранить страницу» читает живой адрес, ресурс и DOM после переключения проекта Search Console без перезагрузки.
- Скрытые старые таблицы и отчёты других проектов исключаются; ресурс проверяется по метаданным таблицы. Настоящая неоднозначность остаётся ошибкой.
- Короткое ожидание отрисовки и повторная проверка адреса защищают от записи старого проекта в новый.
- Обновлённый сборщик заменяет старые экспортированные функции при повторном подключении без второго автоматического наблюдателя.
- Ожидание доступа к папке объясняется по-русски с точным путём разрешения. Локальная история и формат JSON сохранены.

После установки обновите расширение и один раз перезагрузите вкладку Search Console.
