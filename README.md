# SEO / инспектор 0.1.12

Значки копирования в отчётах теперь копируют только нормализованный домен: example.com, без протокола, www, порта, пути, параметров и завершающего слеша. Другие поддомены сохраняются (blog.example.com). Открытие сайта и выгрузка CSV по-прежнему используют полный URL. Кнопка COPY в шапке popup сохраняет полный URL страницы.

Рядом с каждым доменом в сводке есть переключатель «Не проверено / Проверено ✓». Отметки ставятся вручную, сохраняются в текущем отчёте и восстанавливаются после закрытия страницы или перезапуска фонового модуля. Повторное нажатие снимает отметку. Домен и www-вариант имеют общую отметку внутри отчёта; другие отчёты ведут собственные отметки. Открытие сайта и копирование URL автоматически ничего не отмечают. Фильтры и CSV статистики работают как прежде.

Отчёты конкурентов также имеют компактные значки копирования URL и открытия сайта. В сводке и деталях копируется только домен. Рядом с «CSV сводки» доступна ссылка «Проверить ссылки» на инструмент Keywords Everywhere; данные отчёта туда автоматически не передаются.

Названия отчётов показывают местные дату и время, поисковик, первый запрос и количество запросов в скобках. «Удалить отчёт» после подтверждения удаляет выбранный отчёт вместе с его черновыми данными; остальные отчёты сохраняются. Удалённый отчёт не восстанавливается при повторной финализации прерванного сбора. Значки уменьшены, подписи доменов и URL увеличены.

Расширение запоминает последнюю открытую вкладку раздела глобально для всех сайтов. При следующем открытии popup восстанавливается тот же раздел.

Кнопка LINKS → «Подсветить ссылки» после подсветки прокручивает исходную страницу к первой видимой ссылке по текущему фильтру. Если совпадений нет, положение страницы сохраняется. Адрес ссылки не открывается.

Возможности версии 0.1.7:

- Плашка на выдаче Google/Яндекса по умолчанию свёрнута; раскрытие запоминается. Во время проверки остаются видны прогресс и «Стоп».
- Режим «Сбор конкурентов»: по одному запросу на строку, Google или Яндекс, ТОП30 или ТОП100. Сбор начинается только по ▶. Дубликаты объединяются; максимум20 запросов. По завершении открывается отдельная страница результатов; она также доступна из SEARCH → «Отчёты конкурентов».
- Отчёт показывает частоту домена по запросам, лучшую позицию, среднюю из лучших позиций по каждому запросу и подробные URL/места. Есть фильтры по домену и запросу, отдельные CSV сводки и деталей для Excel. www объединяется с основным хостом, остальные поддомены различаются. При короткой выдаче сохраняется фактически собранный объём; после «Стоп» доступен частичный отчёт. Отчёты хранятся локально в IndexedDB расширения.
- Кнопки «+» рядом с видимыми подсказками Google/Яндекса и фразами Wordstat добавляют фразу в общий список анализа. «✓» отмечает уже добавленные фразы; нажатие не запускает поиск. Список сохраняется локально и доступен для редактирования в плашке «Сбор конкурентов», в том числе в другой вкладке. Разрешение Wordstat ограничено wordstat.yandex.ru; API Wordstat и платные сервисы не вызываются.

Локальное расширение Chrome Manifest V3 на русском языке. Установка: откройте chrome://extensions, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите C:/ai/chrome-seo. Сборка и зависимости не нужны.

- Строка URL: полный адрес доступен при наведении; COPY копирует его целиком и сообщает результат. Статус правил индексации обновляется после анализа без блокировки интерфейса: зелёный — проверенные правила разрешают индексацию, красный — noindex, жёлтый — обход закрыт robots.txt, янтарный — проверка неполная. Причины доступны при наведении и через доступное имя статуса. Проверяются meta robots/Googlebot/Яндекс, robots.txt текущего сайта и доступный X-Robots-Tag. Запрет обхода не означает noindex; nofollow и canonical сами по себе не запрещают индексацию. Фактическое наличие URL в индексе не проверяется. Перенаправления запросов и применимый unavailable_after дают неполную проверку: даты этого правила автоматически не интерпретируются.
- IN LIST в строке URL: зелёный, если домен страницы встречается среди URL текущего списка; красный, если не встречается. Регистр, www, завершающая точка, схема, порт и путь не учитываются; остальные поддомены различаются. Без актуальной страницы, выбранного списка или доступных данных статус нейтральный; пояснение доступно при наведении и фокусе. Списки и навигация обновляют статус.
- META: title, description, canonical, robots, язык, Open Graph, H1–H6, изображения/alt и число слов.
- KEYS: независимые слова через пробел, Unicode-границы, подсчёты по категориям и обратимая разноцветная подсветка. Всего = BODY; P/A пересекаются с BODY, заголовки считаются отдельно; TITLE/META не входят в BODY. OTHER — текст вне ближайших P/A/H1–H6.
- MICRO: JSON-LD с ошибками разбора, microdata и RDFa.
- LINKS: все внешние HTTP(S)-анкоры, фильтр по домену, rel и подсветка. Красный: nofollow/ugc/sponsored либо robots nofollow/none; зелёный: эти ограничения отсутствуют. Это не проверка индексации. Поддомены считаются внешними.
- LINKS → «В список»: сохраняет текущую исходную страницу в общий выбранный список, с пустым комментарием и тегами rel внешних ссылок по текущему фильтру. Перед сохранением анализ и список обновляются. Теги приводятся к нижнему регистру и объединяются; follow добавляется при наличии ссылки без nofollow/ugc/sponsored. noopener сохраняется вместе с follow; robots nofollow/none добавляет nofollow и исключает follow. Без совпадений или выбранного списка кнопка недоступна. Черновик LISTS сохраняется.
- SEARCH: обычные запросы Google/Яндекса, отдельные site:домен и site:текущий URL. Запрос, целевой домен и независимый фильтр ссылок сохраняются локально. На www.google.com/search, www.google.ru/search, yandex.ru/search и yandex.com/search подсвечиваются результаты целевого домена. На плашке самой выдачи доступна отдельная автопроверка наблюдаемой органической позиции; проверка индексации отдельным API не выполняется.

- LISTS: общий текущий список, сохранение URL/title текущей HTTP(S)-страницы с комментарием и тегами независимо от SEO-анализа. Полная библиотека открывается отдельной вкладкой, включая запуск с внутренних страниц Chrome.
- Библиотека: создание/переименование/удаление списков, поиск по URL/title/комментарию/тегам, редактирование и удаление строк. Теги вводятся через запятую; подсказки принадлежат выбранному списку и сохраняются после удаления строк.

Основная копия списков находится в Chrome storage. В библиотеке «Подключить папку JSON» открывает системный выбор папки с разрешением записи: расширение автоматически зеркалирует данные в seo-lists.json. Существующий валидный файл объединяется безопасно; неподходящий файл не перезаписывается. При потере разрешения или ошибке записи локальное сохранение продолжается, интерфейс показывает ожидание синхронизации. Кнопка «Разрешить доступ / синхронизировать» повторно запрашивает доступ. Экспорт/импорт JSON доступны без папки; импорт объединяет записи. Перед удалением расширения экспортируйте резервную копию. Старые файлы версии 1 без тегов совместимы. Системный выбор папки и повторная выдача разрешения требуют ручной проверки в Chrome.

Разрешения: activeTab, scripting, storage и узкий доступ к https://api.deepseek.com/* для AI, https://openpagerank.keywordseverywhere.com/* для Open PageRank и https://api.keywordseverywhere.com/* только для баланса KE. content_scripts ограничены Google/Yandex com/ru (основные и www-варианты); плашка включается только на выдаче и страницах проверки доступа. Для определения переходов/капчи добавлены узкие разрешения этих поисковых хостов. SEO-анализ выполняется локально. Кнопка «Отправить в DeepSeek» передаёт задание, проверенный текст и описание выбранной формы в DeepSeek. Отдельная кнопка OPR отправляет только имя хоста, кнопка баланса KE не отправляет данные страницы; robots.txt и HEAD текущего URL запрашиваются у текущего сайта с существующим activeTab, без дополнительных разрешений. HEAD — повторный запрос, его ответ может отличаться от навигации; ошибки доступа, таймауты и недоступные заголовки дают неполную проверку; поисковые кнопки открывают выбранный запрос в новой вкладке. Анализируется DOM главного документа на момент нажатия. Внутренние страницы Chrome, магазин расширений, iframe, shadow DOM и внешние документы не анализируются. Из HTTP-заголовков учитывается только доступный X-Robots-Tag повторного HEAD-запроса. Подсветка требует CSS Custom Highlight API; очистка удаляет только собственную подсветку расширения. Динамические изменения страницы могут потребовать повторного анализа.

Проверки: `npm install`, `npm run check`, `npm test` (браузерные поведенческие проверки через Playwright). В Windows runner использует установленный Chrome; иначе установите браузер командой `npx playwright install chromium`. Путь можно указать переменной `CHROME_PATH`. Для использования расширения зависимости не нужны.

Для версии 0.1.12 пройдены синтаксические проверки и 57 целевых проверок: 32 действий с отчётами (включая копирование только домена) и 25 отметок сайтов. Полный набор предыдущей версии 0.1.10 — 385 проверок. Во время автоматических проверок буфер обмена и внешние страницы подменяются фикстурами; сами отчёты проверяются через настоящий worker и IndexedDB. Остальной набор проверяет анализ страницы, списки, историю, AI, показатели, сбор выдачи и запоминание раздела. Runner загружает исходное расширение в Chrome, проверяет content script поиска и local storage; формы popup тестируются через мост к анализатору в настоящем браузере. Списки проверены через настоящий MV3 worker, Chrome storage, IndexedDB и реальную OPFS-папку: сохранение, теги, таблица, экспорт, перезапуск worker, конфликт внешнего изменения и отказ разрешения. Метаданные активной вкладки для popup подставляет тестовый мост; системный выбор папки и реальный запрос разрешения проверяются вручную. Автоматизация не нажимает кнопку расширения на панели Chrome для выдачи activeTab.

Название нового списка и черновик комментария/тегов в LISTS сохраняются локально. Проверьте результат перед повторным нажатием «Создать»/«Сохранить»: автоматического повтора нет. Если кнопка недоступна, откройте chrome://extensions и нажмите «Обновить» у SEO / инспектора. Простое обновление вкладки не обновляет установленный манифест. AI и SETTINGS (0.1.12):

1. После обновления файлов нажмите круговую стрелку у расширения на chrome://extensions и откройте popup заново. Если интерфейс сообщает о старом фоновом модуле, используйте «Перезапустить расширение» в SETTINGS. Списки сохраняются; не удаляйте расширение. Несостоявшееся сохранение ключа автоматически не повторяется: после перезапуска введите его один раз заново.
2. SETTINGS: сохраните API-ключ DeepSeek и модель. По умолчанию deepseek-flash, также доступна deepseek-v4-pro. Пустой ввод сохраняет существующий ключ; «Удалить ключ» удаляет только его. Ключ хранится в IndexedDB расширения, не включается в списки, экспорт или доступное content scripts Chrome storage; это локальное хранение, не зашифрованный сейф.
3. AI: введите задание, нажмите «Загрузить страницу», проверьте/отредактируйте текст. Наиболее подходящая форма комментария выбирается автоматически; можно выбрать другую или «Без формы». Считываются до24000 символов видимого текста, до12 форм и40 безопасных полей формы. Скрипты, стили, меню, скрытые элементы и существующие значения полей исключаются; iframe, shadow DOM и contenteditable не поддерживаются.
4. «Отправить в DeepSeek» получает структурированный JSON: comment и массив fields с id/value известных полей. Пользователь видит редактируемый комментарий и подписанные поля. Модель заполняет обязательные поля и email: использует данные из задания, иначе предлагает вымышленные имя и контакты с email/сайтом на example.com или example.org. Реальность и доступность сгенерированных контактов не подтверждаются. Некорректные JSON, неизвестные поля, неверные email/URL и обрезанные ответы отвергаются.
5. Проверьте предложения и нажмите «Заполнить форму». Вставляются только безопасные поля текущей ранее считанной формы; URL/контекст/исходные элементы проверяются повторно. Пароли, скрытые поля, файлы и согласия не заполняются; кнопка отправки не нажимается. Обработчики input/change намеренно не запускаются: сайты, которым они нужны для сохранения значения, могут потребовать ручной вставки. Комментарий можно скопировать отдельно.

Задание сохраняется локально; ответ и подготовленный текст остаются в текущем popup. Закрытие popup может прервать получение ответа; автоматического повтора платного запроса нет. Запрос использует только официальный HTTPS endpoint, без cookies и переходов на другой адрес, с таймаутом30 секунд. Настоящий платный вызов и качество ответа вашей модели проверяются вручную с вашим ключом; автоматические тесты подменяют API и не расходуют баланс.

API-контракт сверён с [официальной документацией DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/) и [быстрым стартом](https://api-docs.deepseek.com/quick_start/agent_integrations/).


Бесплатные показатели Keywords Everywhere:

- В шапке OPR показывает Open PageRank0–10 текущего хоста. «Проверить» делает ровно один запрос; повторный клик во время запроса игнорируется. При открытии popup, сохранении/удалении ключа, смене вкладки/адреса и обычном «Обновить» внешний OPR API не вызывается. Результат предыдущего домена сбрасывается локально, поздний ответ не переносится на новую страницу. В подсказке источник, домен, дата данных и место в рейтинге. Неизвестное значение — прочерк; нулевой известный рейтинг отображается0. Поддомены получают только собственный host score, основной домен не подставляется вместо неизвестного поддомена; www провайдер считает основным доменом.
- В SETTINGS сохраните отдельный [ключ Open PageRank](https://keywordseverywhere.com/account/openpagerank), обычно opr_live_…. Это не общий ключ Keywords Everywhere из account#key. Используется бесплатный лимит OPR; по исчерпании квоты запрос завершается ошибкой, автоповтора/покупки/пополнения нет. Бесплатный план у провайдера имеет ограничения IP;403 сообщает проверить доступ и настройки аккаунта.
- «KE … кр.» показывает остаток общих кредитов Keywords Everywhere после нажатия ↻. Для него в SETTINGS есть отдельный общий [ключ KE](https://keywordseverywhere.com/account#key). Выполняется только чтение баланса GET/v1/account/credits; платные методы трафика, ключевых слов, ссылок и другие методы данных KE не подключены. Сохранение ключа и открытие popup баланс автоматически не запрашивают. OPR-лимит проверок не выдаётся за кредиты KE.
- Оба ключа хранятся отдельно от DeepSeek в приватной IndexedDB расширения, не выдаются content scripts, не попадают в списки URL или экспорт. Пустой ввод оставляет прежний ключ; удаление одного не затрагивает другие. Это локальное хранение без шифрования.
- Запросы идут только на фиксированные официальные endpoints с Bearer ключом, без cookies, перенаправлений и автоматических повторов, с ограничением времени/размера ответа. Общий ключ KE применяется только к API KE, ключ OPR — только к OPR. После обновления манифеста нужен перезапуск всего расширения на chrome://extensions. Кнопки восстановления в SETTINGS не удаляют списки/другие ключи и не повторяют сомнительное сохранение.

Контракты: [Open PageRank](https://keywordseverywhere.com/openpagerank/docs), [баланс KE](https://api.keywordseverywhere.com/docs/#/miscellaneous/get_credits). Последний ответ относится только к явно выполненной проверке; без запроса отображается прочерк. Автоматические тесты используют подменённые ответы обоих провайдеров и не расходуют квоты или кредиты.


Автопроверка позиции0.1.12:

1. Откройте обычную выдачу Google или Яндекса. На нижней плашке укажите домен и поисковый запрос, затем нажмите «▶ Старт». Запуск всегда открывает первую страницу текущего поисковика. Ввод полей, открытие выдачи и изменения сохранённого домена сами проверку не запускают.
2. Плашка показывает текущую страницу и число просмотренных органических результатов. После считывания страницы следующая открывается с паузой около2,5 секунды. Останавливается при первом совпадении домена (с его поддоменами), после10 просмотренных страниц или100 органических результатов. Позиция100 включена.
3. Отчёт содержит общую наблюдаемую позицию, номер страницы, место на странице и найденный URL в состоянии проверки. Пример: позиция13, страница2, место3. При разном числе органических карточек на страницах суммируются реально считанные карточки; отдельные дополнительные ссылки одной карточки и распознанная реклама не считаются самостоятельными результатами. Повтор страницы не считается повторно, одинаковый URL в разных самостоятельных результатах остаётся самостоятельным местом.
4. «Стоп» отменяет ожидающий переход. Закрытие плашки тоже останавливает проверку. Одновременно выполняется одна проверка в привязанной вкладке; для другого поисковика сначала остановите текущую. Ручная смена запроса/страницы, непризнанная разметка, непонятная tracking-ссылка или отсутствие безопасной ссылки следующей страницы ставят проверку на паузу вместо ложного точного результата.
5. CAPTCHA и запрос согласия требуют ручного действия пользователя. Расширение их не проходит и не обходит; после ручного прохождения на ожидаемой странице нажмите «Продолжить». Контекст/счётчики хранятся в chrome.storage.session и переживают остановку фонового worker в рамках сеанса Chrome; перезапуск браузера завершает сеансовое состояние. Другие вкладки и устаревшие сообщения не могут подменять результаты проверки.

Это позиция органической карточки в реально просмотренной персонализированной выдаче данного браузера, языка и региона. Карты, AI-блоки, видео и меняющаяся вёрстка могут отличаться от обычной органики; при невозможности уверенно распознать результаты проверка останавливается. Google может вернуть меньше100 результатов. В этом случае отчёт о просмотренном объёме не означает проверку всего топ100. Платные SERP API не используются; запросы поиска отправляются непосредственно в выбранный поисковик только после ▶. Автоматические тесты маршрутизируют страницы на локальные фикстуры, не выполняя массовый живой обход.
