# 0.1.14

[Все выпуски](README.md) · [Руководство](../USAGE.md)

- Исправлен переход по выдаче Яндекса при явном автоматическом исправлении опечатки: например, адрес содержит «уровки», а ссылка следующей страницы — «уроки».
- Исправление принимается только по согласованным видимым признакам Яндекса: уведомление, поле запроса и ссылка отмены. Соседняя страница сохраняет регион и остальные параметры.
- Исходный запрос сохраняется в отчёте; исправленный используется для навигации. При переходе к следующему запросу списка исправление сбрасывается.
- Скрытые и отключённые ссылки, неоднозначные поля и неподтверждённая смена запроса продолжают останавливать обход.
- Улучшено различение отсутствующей и некорректной ссылки следующей страницы.
- Сохранены остановка, восстановление после перезапуска фонового модуля и ручное прохождение CAPTCHA.
