# 0.1.13

[Все выпуски](README.md) · [Руководство](../USAGE.md)

- Исправлена пауза при переходе по выдаче Яндекса, когда к адресу добавляется служебный параметр `rnd`.
- Порядок параметров, эквивалентное кодирование пробелов и варианты `/search` / `/search/` не мешают считыванию той же страницы Яндекса.
- Смена запроса, региона, фильтров, поискового хоста или номера страницы продолжает останавливать обход. Следующая страница должна быть соседней и сохранять контекст поиска.
- Счётчик учитывает реально найденные органические результаты, включая страницы с 15 результатами; повторное служебное изменение URL их не удваивает.
- Сохраняются ручное прохождение CAPTCHA и строгая проверка вкладки и отправителя сообщения. Поведение Google сохранено.
