# SEO / инспектор

Локальное расширение Chrome на русском языке для анализа страницы и работы с SEO.
Работает без сборки; зависимости нужны только разработчикам для тестов.

## Возможности

- META: метатеги, заголовки, изображения и число слов.
- KEYS: поиск слов и обратимая подсветка; MICRO: JSON-LD, microdata и RDFa.
- LINKS: внешние ссылки, rel, фильтр по домену и подсветка на странице.
- LISTS: списки URL с комментариями и тегами, импорт/экспорт JSON и зеркало в папке.
- SEARCH: поиск Google/Яндекса, наблюдаемая позиция и сбор конкурентов ТОП30/ТОП100.
- Отчёты: частота доменов, позиции, фильтры, CSV, ручные отметки проверенных сайтов.
- AI: черновик комментария через DeepSeek и заполнение формы после проверки пользователем.
- Ручные проверки Open PageRank и баланса Keywords Everywhere с отдельными ключами.

SEO-анализ выполняется локально. Внешние API вызываются отдельными кнопками.
Правила robots не подтверждают фактическое наличие страницы в поисковом индексе.
Подробности, ограничения и работа с данными: [руководство](docs/USAGE.md).

## Установка в Windows

1. Если Git ещё не установлен, установите его с [официального сайта Git for Windows](https://git-scm.com/install/windows).
   Если командная строка уже была открыта, закройте её и откройте заново после установки.
2. Нажмите **Win + R**, введите `cmd` и нажмите Enter.
3. Проверьте, что Git доступен:

```cmd
git --version
```

4. В той же командной строке скачайте репозиторий:

```cmd
cd /d "%USERPROFILE%"
git clone https://github.com/klishinoleg/chrome-seo.git
cd chrome-seo
```

Папка расширения будет находиться в `%USERPROFILE%\chrome-seo`.
Команду `git clone` выполняют один раз при первой установке.

5. Откройте в Chrome адрес `chrome://extensions`.
6. Включите **Режим разработчика** в правом верхнем углу.
7. Нажмите **Загрузить распакованное расширение**.
8. Выберите папку `%USERPROFILE%\chrome-seo`, внутри которой лежит `manifest.json`.
9. Откройте обычную HTTP(S)-страницу и нажмите значок расширения.

Для установки не нужны Node.js, `npm install` или команда сборки.
Инструкция Chrome: [загрузка распакованного расширения](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

## Обновление

1. Откройте командную строку: **Win + R** → `cmd` → Enter.
2. Перейдите в уже скачанную папку и получите изменения:

```cmd
cd /d "%USERPROFILE%\chrome-seo"
git pull --ff-only
```

Команда обновляет существующую копию; повторно клонировать репозиторий не нужно.
Если клон находится в другой папке, в команде `cd /d` укажите именно её.
Если Git сообщает о локальных изменениях или расходящейся истории, остановитесь
и сохраните свои изменения перед разбором ошибки. Не удаляйте папку для обхода ошибки.

3. Откройте `chrome://extensions`.
4. На карточке **SEO / инспектор** нажмите круговую стрелку перезагрузки расширения.
5. Закройте старый popup и откройте его заново.
6. Обновите открытые страницы сайтов и вкладки отчётов/библиотеки клавишей F5.

Одного обновления страницы сайта недостаточно: Chrome должен перечитать расширение.
Если интерфейс сообщает о старом фоновом модуле, повторите перезагрузку карточки.

## Данные и первое использование

Оставляйте папку расширения на месте: Chrome загружает файлы непосредственно из неё.
Не удаляйте расширение ради обновления — удаление стирает его локальные данные.
Перед удалением или переносом экспортируйте списки в JSON через библиотеку.
Обычное обновление файлов и перезагрузка расширения сохраняют локальные данные.

В popup выберите нужный раздел и выполните анализ страницы.
На выдаче Google/Яндекса сбор запускается вручную кнопкой ▶ на нижней плашке.
CAPTCHA и согласия проходят вручную; результат зависит от выдачи вашего браузера.
В отчётах копируется домен, открывается полный URL, отметки проверки ставятся вручную.
Верхняя кнопка COPY в popup копирует полный URL страницы.
